Structured multi-domain integration of M1–M4 outputs for glaucoma follow-up.

How M5 works. M5 integrates the outputs of OFTY tools M1–M4 into a single multi-domain glaucoma assessment. If you have already used those tools in this browser session, your data is imported automatically; otherwise, you can enter values manually.
  • Each domain block can be filled from imported data or completed manually using the form.
  • Use the × button on a domain block to exclude that module from the integrated summary (re-includable at any time).
  • M2 (target IOP) is required for IOP comparison; M1, M3 and M4 are optional but improve the integrated assessment.
  • Click Generate Integrated Summary when ready — M5 never runs automatically.

Limitations:
Inherits the limitations of upstream M1–M4 outputs. Discordance between structural and functional domains is flagged but not algorithmically resolved. Assumes input coherence across modules (same patient, same eye, same monitoring window).

Rule-based integration of OFTY M1–M4 outputs into a structured multi-domain glaucoma assessment. Does not replace physician judgment or clinical evaluation.

This tool combines the structured outputs of OFTY-Gx-M1, M2, M3, and M4 into a single integrated assessment using deterministic rule-based logic. No machine learning, no probabilistic models, no treatment recommendations are generated.

The integrated interpretation surfaces structural–functional patterns, IOP target adherence, and confidence/risk levels in descriptive form only. Discordance between domains, signal-limited contexts (high myopia, ERM, RNFL floor effect), and incomplete data are explicitly flagged rather than masked.

The output is a structured decision-support aid consistent with current glaucoma guidelines (EGS 6th ed., AAO PPP 2021). It establishes computational integration of upstream module outputs and has not been clinically validated against expert adjudication or longitudinal outcomes.

The clinician retains full responsibility for all diagnostic and therapeutic decisions. This tool is intended as a decision-support aid and is not a substitute for clinical evaluation, specialist consultation, or comprehensive examination. Not intended for patient self-use.
