Disclaimer

Evidence-informed biomechanical IOP context based on ORA and/or Corvis ST device measurements. Does not replace clinical judgment or comprehensive tonometric evaluation.

This tool applies deterministic rule-based logic to contextualize intraocular pressure against corneal biomechanical parameters derived from the Ocular Response Analyser (ORA) and/or the Corvis ST. It is intended as a structured decision-support aid, not as a standalone diagnostic conclusion. The Core reference (GAT–CCT correction) is not a true IOP estimate and is not suitable for target-IOP comparisons.

Device measurements may be affected by corneal disease, ectasia, prior refractive surgery, media opacity, and instrument variability. Corneal Hysteresis, SSI, and SP-A1 are reported as biomechanical context only and never modify the pressure value. Cross-device comparison (ORA vs Corvis) requires same-session readings and clinician confirmation; without confirmation the comparison is flagged as unvalidated and reported as numerical only. Device pressures are never fused into a single value and no device is designated as primary.

Device-derived values are interpreted as biomechanical context and are never fused into a single pressure value. The M1 Core GAT/CCT reference is a contextual estimate, not true IOP. Target-IOP integration is not active in this module.

When only ORA or only Corvis is selected, biomechanical context is necessarily branch-specific. Cross-device comparison is available only in Both mode and requires same-session clinician confirmation.

The clinician retains full responsibility for all diagnostic and therapeutic decisions. This tool is intended as a decision-support aid, consistent with current glaucoma guidelines (EGS 2025), and is not a substitute for clinical evaluation. Not intended for patient self-use. Not a certified medical device.
